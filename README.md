# Hyprland Configuration

## Dependencies

- `fuzzel` launcher
- `fd` find utility

## Scripts

### Find Music Fish Script

You can add as many music directories as you wish to `music_dirs` variable at the beginning of the script.
Full file paths and their short versions supplied to Fuzzel are automatically cached in `~/.cache/find_music/albums-db.txt` and `~/.cache/find_music/artists-db.txt`.
